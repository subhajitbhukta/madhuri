# Madhuri Birthday Surprise — Step-by-step edition

A mobile-first birthday experience inspired by the reference screenshots.

## Run
Open `index.html` in a browser, or run `python -m http.server 5500` and visit `http://localhost:5500`.

## Music
The page has a Play Music button, but browsers require a user click before audio can play. Place a licensed/royalty-free MP3 named `birthday-music.mp3` in this folder. Music is intentionally not bundled.

## Customize
Edit the text in `index.html`. The birthday countdown target is in `script.js` as `2026-10-30T00:00:00`.

## Deploy
Upload these files to Netlify, Vercel static hosting, or another static host. A custom domain requires owning the domain and setting the DNS records provided by the host.
